# 🎯 Behavioural Signals & Competencies

*Behavioural rounds score a fixed list of competencies, not charm. Know the list, know what evidence each needs, and map every story to it.*

## 🧭 What interviewers assess
<!-- related: behav-17, behav-19 -->

### 📋 Core skills

| Skill | Evidence they look for |
|---|---|
| Communication | Clear, structured, tailored to the audience |
| Decision making | Options weighed, trade-offs explicit, data used |
| Initiative | Acted without being asked; spotted the problem first |
| Organisation | Planned, sequenced, tracked |
| Time management | Prioritised under constraints; cut scope wisely |
| Flexibility | Changed course when facts changed |
| Leadership | Moved people, with or without authority |
| Problem solving | Root cause, not symptoms |

> 🔑 Answers are scored against a rubric; a vague story scores "no evidence", not "bad".

## 🌐 Culture & values signals
<!-- related: behav-9, behav-13, behav-19, behav-26 -->

| Signal | What it means |
|---|---|
| Ambiguity & pressure | Acting sensibly when the plan is unclear; changing course fast |
| Feedback reception | Taking feedback from seniors **and** juniors, and acting on it |
| Challenging the status quo | Questioning assumptions despite pushback, with data |
| User-centricity | Putting users (internal or external) ahead of convenience |
| Ethical judgement | Making the unpopular-but-right call and standing by it |
| Team trust | Building psychological safety and inclusion |

## 🚩 Leadership signals
<!-- related: behav-12, behav-21, behav-24, behav-30 -->

| Signal | What it means |
|---|---|
| Complex project delivery | Many stakeholders, scale, timeline crunch |
| Business impact | Cost cut, process improved, metric moved |
| Strengths-based teamwork | Matching work to people's strengths, not just your own |
| Self-development | Seeking feedback, learning deliberately |
| Cross-context collaboration | Different working styles, time zones, disciplines |
| Tool / AI fluency | Using modern tooling to multiply output responsibly |

## 🗺️ Signal → likely question
<!-- related: behav-6, behav-25, behav-26 -->

| Signal | Typical prompt |
|---|---|
| Ambiguity | "Tell me about a time requirements were unclear." |
| Feedback (junior) | "How do you handle feedback from less experienced teammates?" |
| Feedback (senior) | "Tell me about tough feedback you received." |
| Status quo | "When did you challenge an established process?" |
| User-first | "When did you advocate for the user against pressure?" |
| Ethics | "Tell me about an unpopular decision you made." |
| Team trust | "How do you build trust on a new team?" |
| Complex project | "Walk me through a complex project you led." |
| Impact | "What's your proudest measurable impact?" |
| Strengths-based | "How do you delegate?" |
| Self-dev | "How do you stay current?" |
| Working styles | "Tell me about working across time zones or styles." |
| Goal setting | "Describe two goals you set and how you tracked them." |

> 📝 Practice: for each row, name the story that answers it in one sentence. Blank rows are your prep gaps.
